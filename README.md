# CineMatch — Movie Recommendation System

A Streamlit web app that recommends movies using content-based filtering with TF-IDF and cosine similarity.

## Files needed to run the app

```text
Movie_Recommender_System/
├── app.py
├── requirements.txt
├── README.md
└── models/
    └── movie_recommender.joblib
```

Copy the `models/movie_recommender.joblib` file generated by your recommendation notebook into the `models` folder. The app cannot run without this artifact.

## Run locally

Activate your project's virtual environment, then run:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Open the local URL printed in the terminal (usually `http://localhost:8501`).

## Deploy

The app can be deployed from a GitHub repository using Streamlit Community Cloud. The repository must include `app.py`, `requirements.txt`, and `models/movie_recommender.joblib`.

Before deployment, pin the scikit-learn version in `requirements.txt` to the version used when the `.joblib` file was created. To check your local version, run:

```bash
python -c "import sklearn; print(sklearn.__version__)"
```

For example, replace `scikit-learn` in `requirements.txt` with `scikit-learn==YOUR_VERSION` (using the version printed by that command). Also select the same Python version in the Streamlit Community Cloud deployment settings where possible.
